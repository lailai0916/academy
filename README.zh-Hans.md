# lailai's Academy

这是 [README.md](README.md) 的补充说明。

Academy 是面向高中生个人用户的简体中文 AI 自学平台。它不包含家长端、教师端、学校管理端
或付费体系。平台首期以英语单词和古诗词为切入口，逐步承载人教版（部编版）普通高中课程内容。

学习系统使用 FSRS 安排复习，并把每次回答转换为可审计的复习事件。题目会从识别逐步升级到
拼写、语境应用、补空与接句；至少间隔 24 小时后的结果会单独计入延迟测试正确率。AI 用于解释
错误和生成同知识点变式，但教材内容与标准答案始终来自结构化内容库。
