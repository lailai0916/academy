# Academy 架构说明

## 系统边界

Academy 只服务学生个人用户。账号通过邀请码建立；管理员负责邀请码、AI 接口和教材内容。
平台不包含家长、教师、学校或支付角色。

## 运行结构

| 层   | 技术                                             | 责任                                      |
| ---- | ------------------------------------------------ | ----------------------------------------- |
| Web  | React 19、Vite、React Router、`@lailai/ui`       | 学习、社交、个人与管理界面                |
| API  | Fastify 5、Zod                                   | 认证、权限、计划、练习、AI 与社交业务     |
| 数据 | PostgreSQL、Drizzle ORM                          | 用户、内容、复习事件、FSRS 卡片与社交关系 |
| 调度 | `ts-fsrs`                                        | 根据稳定性、难度和遗忘概率安排下次复习    |
| AI   | OpenAI 兼容 Chat Completions，默认 `gpt-5.6-sol` | 基于已审核内容生成讲解和变式              |
| 边缘 | Caddy                                            | TLS、静态文件、SPA 回退与 `/api` 反向代理 |

## 关键数据流

1. 管理员生成邀请码；数据库只保存 SHA-256 哈希，明文只返回一次。
2. 学生注册后获得随机会话 token；浏览器仅持有 Secure、HttpOnly、SameSite=Strict Cookie，
   数据库只保存 token 哈希。学生可查看经过概括的设备和网络信息、撤销单个设备，并在修改
   密码时自动退出其他设备。
3. 教材条目使用稳定的 `content_items` 身份，并把每次导入、编辑、发布、归档和恢复写为不可变
   `content_versions`。管理员可在内容工作台编辑与查看修订记录；草稿可与上一已发布版本并存，
   完整性问题会阻止发布。
4. 内容导入采用“预检—确认”两阶段流程，预检凭据包含当时的内容版本基线；应用期间若任一
   条目变化，整个批次原子拒绝。批次回滚通过追加恢复版本实现，不删除原导入记录；此后已被
   单独编辑的条目会跳过，避免覆盖管理员的新决定。
5. 每日计划先安排当前年级的已发布到期内容，再按每日容量补充新内容；任一学科内容不足时，
   剩余容量自动分配给另一学科。
6. 学生可以按教材单元、到期项目或历史错题建立学习会话；诊断会优先覆盖对应年级已发布
   内容中的不同教材单元。每名学生仅保留一个进行中的学习会话，重复创建请求恢复原会话。
7. 学习会话会固定每道题的内容身份与版本。每次回答形成不可变的 `review_events` 并记录该
   版本；若内容在答题期间被替换，旧题结果仍保留，但不会更新当前 `learning_cards` 的 FSRS
   状态。反应时间评价按选择、拼写、语境填空和默写题型使用不同阈值。答错或查看答案的内容
   会在至少两个其他项目后回练一次；已被替换的内容版本不追加回练。
8. 学习会话可暂存或结束；结束后保留已完成记录，未答内容不进入结果。会话结果由事件记录
   生成首轮正确率、回练纠正数、反应时间、当前掌握度和本组错题；近 7–90 天记录汇总为学习
   分析。
9. 至少间隔 24 小时的复习单独进入延迟正确率；稳定期达到 21 天的项目计入长期记忆。发布
   答案语义发生变化的新版本时，对应学习卡会重置，非答案性修订则保留学习状态。
10. 好友申请、接受申请与小组共同目标写入站内通知；共同目标只对小组成员可见，并根据参与后
    的有效学习事件汇总全组进度与个人贡献，不提供成员排行榜。完成项目按会话内的不同内容
    去重；掌握提升使用答题前后的掌握度变化；延迟正确率必须同时达到正确率和最低样本数。
    顶部通知入口不传递敏感学习内容。
11. AI 请求只包含学习会话固定的教材版本、题目和用户本次回答，不发送用户名或个人档案。

## 安全与隐私

- Argon2id 保存密码；登录、注册与修改密码有速率限制；修改密码会撤销其他登录会话；写请求
  校验 Origin；
- 管理权限在 API 强制执行，前端路由隐藏不构成权限边界；
- AI Key 以 AES-256-GCM 加密，密钥只存在生产环境变量；
- API 容器以非 root、只读文件系统和最小 Linux capability 运行；
- PostgreSQL 不暴露公网端口；API 只绑定宿主机 `127.0.0.1:4100`；
- Umami 只加载基础页面统计脚本，不上报答案、用户名或教材内容。

## 当前范围与后续扩展

当前已连通教材单元、分层诊断、错题巩固、会话结果、学习分析、内容版本、修订工作台、批次
回滚、来源追踪、站内通知与小组共同目标。仓库附带的内容量仍仅用于验证产品链路。后续应补充
独立审核角色与版权记录，再扩展学科知识图谱和更复杂的知识追踪。
