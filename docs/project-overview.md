# Academy 项目说明

更新：2026 年 9 月 18 日。

Academy 是面向高中生的开源 AI 自学平台，计划覆盖浙江高考语文、数学、英语、物理、化学、技术六科。我会先用于自己的高二学习，再逐步扩展课程。

## 背景

我在杭州第二中学读高二，曾脱产学习信息学竞赛。退役后需要补文化课，偏好有清晰推导、按专题组织、可以随时追问的教学。补习费用难以支持日常使用；AI 答疑更灵活，但课程、练习和长期复习仍需自己安排。

Academy 要把这些环节接起来，也解决难以主动开始和持续学习的问题。个人经历、研究与作品见[个人介绍](applicant-profile.md)。

## 课程与教学

课程对照教材、知识关系和考试要求组织。典型题型说明方法与适用条件，再用不同情境和综合任务检查应用。

| 学科 | 主要任务                                               |
| :--- | :----------------------------------------------------- |
| 数学 | 概念推导、证明、方法选择与限时解题                     |
| 物理 | 研究对象、过程分析、建模与实验                         |
| 化学 | 结构、反应条件、计算与实验推理                         |
| 英语 | 词汇、听力、阅读和写作                                 |
| 语文 | 文言与古诗词、阅读依据、答案组织和写作                 |
| 技术 | 信息技术与通用技术分别安排，覆盖程序、制图、电路和设计 |

每节课先检查必要基础，跳过已会内容。讲解中穿插作答，按错误步骤提供提示；追问保留课程位置，讨论后继续。图形、模拟和程序用于观察条件变化、解释结果。

练习记录帮助程度，测评使用未展示的题目。后续复测检查保持情况，再决定补学或进入新内容。具体规则见[教学方案](learning-system-plan.md)。

## 长期安排

系统保存目标、课程位置、作答和复测记录，用于恢复学习和调整计划。学校作业、测验也可纳入，减少重复安排。

计划分为阶段、周和当天任务，结合先修缺口、近期考试、复习需要和可用时间。漏学后重新排序；持续完不成时减少负荷，保留可以直接开始的小任务。提醒时段由学生选择。

进展以独立表现、延迟保持和考试应用为依据。学习时长只用于估算负荷。

## 当前实现与下一步

现有平台已支持账号、英语词汇与古诗词记忆训练、练习会话、间隔复习、内容版本和 AI 讲解。网站和共享模型已经建立六科课程目录，并将课程教学、独立测评、记忆训练和长期计划分成不同模块；词汇与古诗词不再代替整个学习平台。

首个[动量定理课程](learning-pilot.md)已经接通连续课堂：保存课程位置和每次作答，记录提示与查看解法，允许在非测评步骤追问，使用另备题完成独立测评，并在七天后开放延迟复测。正确答案只保留在服务端；浏览器每次只接收当前步骤。

今日计划已把同年级课程、到期复测、单词和古诗词任务排在同一入口，根据课程运行与当天真实作答显示进度，并可直接开始或恢复。阶段计划、周计划、通用课程编辑和其他学科内容尚未实现，详见[架构说明](architecture.md)。

下一步用这门课完成真实学习，根据作答、提示依赖、操作负担和费用修改。之后再逐步加入其他学科、综合题与整卷训练。开发顺序见[后续计划](project-roadmap.md)。

代码开源，支持普通设备、自部署和模型替换。每月几十元是日常总费用目标，尚需测算。资助申请应列明下一阶段开发内容、课程核对和模型试验的开支；已有设备与资料继续复用。
