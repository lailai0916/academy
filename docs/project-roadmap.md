更新：2026 年 9 月 17 日。

六科课程目录和产品入口已经建立。先完成一个专题的连续教学与复习，英语词汇和古诗词继续作为独立的记忆训练模块。学习与开发分别安排时间。

## 首版

首个专题采用已经设计的[动量定理课程](learning-pilot.md)。用少量独立作答检查基础，整理教材、讲解、练习和另备的测评题，接入前核对答案与评分要求。

沿用当前技术栈，复用账号、模型配置和内容版本，增加：

| 功能     | 完成要求                           |
| :------- | :--------------------------------- |
| 连续课程 | 保存目标、步骤和作答，退出后能继续 |
| 课中追问 | 保存分支问题，讨论后返回原位置     |
| 帮助记录 | 记录提示、查看答案及自行纠正       |
| 独立测评 | 提交前隐藏解答，保留题目与评分版本 |
| 后续复习 | 按课程目标安排复测，记录日期和原因 |
| 费用统计 | 包含实际模型用量与失败重试         |

记忆卡保留 FSRS，概念、方法和解题步骤另行记录。

目前完成了六科共享目录、课程状态、课程入口和三类计划任务接口。上表所列课堂运行数据仍待实现，不以空数据库表代替实际链路。

## 试用与修改

完成课程后用不同情境的题独立作答，再安排延迟检查。可先尝试约一周、约三周的间隔，随表现调整，并记录期间的校内外学习。

核对提示依赖、重复错误、操作负担和费用，优先修正内容与反馈问题。能人工处理的步骤暂时保留，反复影响学习的部分再自动化。

## 扩展

随学习进度增加专题，补齐阅读、写作、实验和技术任务，再建设跨科计划与综合测评。自己的使用稳定后，邀请有补学需求的同学试用，记录不同基础下的困难。

申请资助时，按下一阶段的课程、审核工作和实际模型用量列出预算。
