# Academy 教学与产品方案

讨论稿 · 2026 年 9 月 17 日

面向浙江高中语文、数学、英语、物理、化学、技术六科。以下为待开发方案；现有功能见[项目说明](project-overview.md)，实施顺序见[后续计划](project-roadmap.md)。

## 课程

课程按知识关系组织，用典型题型整理方法，注明适用条件，并以变式和综合任务检查应用。范围对照教材、课标和目标届浙江考试要求，保留来源与版本。学过的内容与独立测评通过的内容分别统计。

| 学科 | 内容与练习                                               |
| :--- | :------------------------------------------------------- |
| 语文 | 文言与阅读依据、答案组织；写作反馈与修改                 |
| 数学 | 定义、推导、证明、反例、方法选择与书面解答               |
| 英语 | 语境词汇、句法、听力、阅读与写作                         |
| 物理 | 研究对象、过程、受力与运动、建模、实验与误差             |
| 化学 | 现象、结构、符号与条件，计算和实验推理                   |
| 技术 | 信息技术与通用技术分别安排：程序、电路、结构、制图与设计 |

每个目标关联教材位置、先修要求、题目和评分标准。实验与制作安排实际操作，词汇和古诗词承担部分积累。[浙江 2026 年 1 月选考命题说明](https://www.zjzs.net/art/2026/1/9/art_31_11862.html)可供参考，正式范围按目标届核对。

## 教学与反馈

每节课围绕一个目标：检查基础、讲解与示范、分步练习、独立应用。已会内容跳过，缺失的前置知识先补。题目和提示的具体设计见[动量课程样例](learning-pilot.md)。

课堂提供课件、作答区和提问入口。图形、模拟和程序用于预测、观察与解释。追问及课外拓展保存课程位置，结束后返回；暂停时保存草稿和进度。课程长度随内容调整。

| 场景 | 帮助规则                         | 记录                     |
| :--- | :------------------------------- | :----------------------- |
| 讲解 | 解释、示范、展开推导             | 接触内容与问题           |
| 练习 | 定位卡点，逐步提示，允许查看解答 | 独立步骤、提示和答案暴露 |
| 测评 | 提交前不给解题提示               | 无辅助作答及评分         |

测评中转入讲解，该次作答记为受辅助。理由不清时追问条件；计算错误检查运算；选法错误比较适用条件；连续受阻则换讲法或缩小步骤。允许学生纠正识别与评分。

公式和图形提供文字说明，支持键盘、移动端和减少动态效果。

## 掌握与复习

每个目标分别记录概念理解、方法选择、独立执行与迁移，附题目、日期和帮助程度。开放题按表达、论证或实验设计等维度评价。

首版使用“未检查、学习中、能独立应用、待复测”等状态。独立应用后可继续课程，延迟结果另行更新；看答案后改对记为订正。

记忆内容沿用 FSRS，推理和表达安排延迟应用题与跨专题测评。复测可从次日、约一周和数周开始尝试，随表现调整间隔与通过条件。

学校作业、测验及课外学习也纳入记录。手写答案先核对转写；识别有疑问时暂缓评价。

## 计划与持续学习

排课前确认教材、缺课章节、当前进度、近期考试和可用时间。先补当前课程依赖的基础，再安排其他遗漏。

计划分为阶段、周和当天任务。阶段安排补缺、综合练习和备考；周计划权衡先修关系、考试与复习；当天给出可直接开始的任务。

中断后恢复进度并重排任务，状态较差时缩小负荷。每周检查完成情况和反复出错的步骤，保留调整原因，允许学生修改。学习时长用于估算负荷，进展依据独立表现和保持情况。

提醒时段、渠道与频率由学生选择，站外提醒需要后台调度和通知权限。必要时可选择可信的人定期复盘。

## 数据与实现

| 对象     | 保存内容                                   |
| :------- | :----------------------------------------- |
| 课程目标 | 学科、教材出处、先修关系、评价要求与版本   |
| 教学单元 | 讲解、交互、追问分支及引用版本             |
| 题目     | 来源、目标、答案、评分要求、版本与展示记录 |
| 作答     | 原始答案、步骤、帮助程度、日期与题目版本   |
| 评价     | 得分、依据、评分方式及人工修正             |
| 掌握情况 | 对应作答、状态、最近检查与待复测内容       |
| 计划     | 时间约束、任务、完成情况与调整原因         |

聊天摘要用于续课，能力判断引用实际作答。教学题与测评题分开管理，标记近似变式。时间统计排除暂停和网络等待。

学习记录默认私有，可导出、删除附件；加入社区不自动公开。模型只接收当前任务所需内容，完整档案保存在平台。

### 内容与评分

教材和标准答案沿用审核发布流程。生成内容先核对再发布，保留审核人、来源及版本。课堂即时答疑提供更正入口。

计算题优先用规则或程序核验。证明、阅读与作文按维度说明评分依据；有分歧时暂缓掌握更新并提供复核。阶段测评请合适的教师抽查。

课件优先复用审核过的组件。生成代码与账号、密钥及学习数据隔离。AI 中断后仍可使用已准备的课程和练习。

### 功能扩展

沿用账号、权限、内容版本和模型配置。词汇与古诗词继续使用现有记忆学习会话；连续课程另建课程运行、教学步骤、追问、帮助记录和学习证据。当前内容类型 `word`、`poem` 不扩成六门学科，原学习记录完整保留。

六科目录和课程状态已经由共享模型统一定义；课程运行与跨科计划仍待开发。长期计划只组合课程、独立测评和记忆复习三类任务，不接管各模块内部的完成规则。

学生端按“今日、课程、课堂、复测、进展”组织，技术配置留在管理页。数据迁移、权限和测试遵循仓库规范。

### 费用

代码开源，支持普通浏览器、自部署和模型替换，课程许可单独管理。每月几十元是包含模型调用的总费用目标。

复用课件和讲解，任务排序与复习到期由程序处理，复杂问题按需调用模型。先比较回答质量，再决定模型分工。统计完整学习周的调用、重试、内容处理、存储及维护成本，并核算高使用量。提供费用上限，到达后由学生选择后续安排。

## 使用评价

先在一个当前需要的专题上持续使用，逐步加入开放题和其他学科。查看：

- 学前、学后和延迟检查的独立作答，注明覆盖范围与难度。
- 换情境后的方法选择、提示依赖和重复错误。
- 计划完成、中断恢复、操作与准备负担。
- 讲解错误、评分分歧、等待和总费用。

使用不同题目，并以部分校内测验或真题作参照。比较学习方式时记录原有基础和投入差异。少量个人结果用于调整自己的学习，不能推断普遍效果。

全科自学还需完整课程、整卷、书面表达和实践任务。到校安排另与家庭和学校讨论。

## 研究参考

- [Kestin 等，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12179260/)：大学物理随机对照研究中，经过设计的 AI 辅导改善了短期学习。未检验高中全科长期自学。
- [Bastani 等，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12232635/)：高中数学研究中，无约束 AI 帮助改善练习，但随后独立考试表现可能变差。教师设计提示缓解了影响，未证明独立考试优于对照组。
- [Roediger 与 Karpicke，2006](https://pubmed.ncbi.nlm.nih.gov/16507066/)；[Cepeda 等，2006](https://pubmed.ncbi.nlm.nih.gov/16719566/)：支持提取练习与分散学习对记忆保持的作用，推理、写作和实验仍需相应任务评价。

完整研究与产品比较见[可行性调查](ai-learning-feasibility-research.md)。
