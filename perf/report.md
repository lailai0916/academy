# Academy 性能验证

2026-10-06；旧版基线：`12ffa8b`。

## 实验室收益

同一台机器逐项交替运行旧版和新版，每版每项 20 次，以下为 p75：

| 实际操作                 |    旧版 |    新版 | 耗时减少 |
| ------------------------ | ------: | ------: | -------: |
| 打开首页并切换主题       |  775 ms |  617 ms |    20.4% |
| 打开登录页并输入用户名   |  730 ms |  551 ms |    24.6% |
| 打开学习首页并搜索词汇   |  914 ms |  775 ms |    15.2% |
| 打开课程目录并进入词汇页 | 1127 ms | 1029 ms |     8.6% |

Chromium 151、1440×900、Fast 4G（20 ms 延迟、512 KiB/s 下载）、CPU 不降速。
禁用缓存，生产构建使用 gzip 9；API 使用相同的合成响应和 20 ms 延迟，分析脚本在两版均禁用。
等待实际 DOM 就绪后完成操作并核对结果，避免自动化元素轮询间隔主导计时；构建和其他浏览器任务不与测速并行。

四项操作下载的 JS 从 202,424 字节降至 128,281–141,367 字节，减少约 30–37%。
Logo 从 71,362 字节降至 33,259 字节，像素完全一致。预加载映射增加的 HTML 也纳入计时与预算。

## 实现与守护

- 页面及应用外壳按需加载，HTML 提前请求当前路由的依赖；认证请求并行。
- 浏览器通过纯目录数据入口读取课程，不下载服务端校验代码。
- 已挂载页面保留组件身份；模块加载失败显示重新加载入口。
- 65 项浏览器检查通过，覆盖权限重定向、课程与记忆页面、搜索快捷键、登录、浏览器历史、草稿保留、加载失败恢复及首帧样式。
- 桌面/手机、浅色/深色共 24 张截图与旧版比较；保留现有组件样式。

这些是受控前端实验结果。本环境直接访问生产站和 PageSpeed 被网络代理拒绝，不能据此推断生产 API 延迟或真实用户收益。
发布工作流另行核对公开 HTML、全部 JS/CSS、Logo 与构建一致，并检查 API 健康状态。

`npm run check:performance` 检查构建 HTML 和全部入口、按需页面的 JS/CSS gzip 预算。
`node scripts/check-performance.mjs --update` 只允许收紧已有预算；必要增量需单独审查预算差异。
原始测量、截图及临时脚本保存在仓库外，Git 只保留运行代码、预算检查与本报告。
